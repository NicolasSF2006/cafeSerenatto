# Serenatto

Link para a página: https://nicolassf2006.github.io/cafeSerenatto/

Serenatto é uma landing page fictícia para uma cafeteria e bistrô. O projeto apresenta informações institucionais, serviços oferecidos, produtos, formulário de contato, modo claro/escuro e componentes interativos usando Bootstrap.

## 🔨 Funcionalidades do projeto

- **Navbar responsiva:** menu fixo no topo com offcanvas em telas menores.
- **Modo claro/escuro:** alternância de tema usando `data-bs-theme` do Bootstrap.
- **Banners visuais:** seções com imagens de fundo para destacar a identidade da cafeteria.
- **Cards de serviços:** apresentação dos principais serviços da cafeteria.
- **Offcanvas lateral:** detalhes adicionais sobre Café & Bistrô, Buffet e Delivery.
- **Cards de produtos:** lista de categorias de produtos oferecidos.
- **Modais de produtos:** janelas com mais informações sobre cada categoria.
- **Formulário de contato:** área para o usuário preencher nome, email, telefone e preferência de contato.
- **Rodapé com redes sociais:** links visuais para canais de contato.

## ✔️ Técnicas e tecnologias utilizadas

- **HTML:** estrutura da página.
- **CSS:** estilos personalizados e ajustes visuais.
- **Bootstrap:** componentes prontos, grid, navbar, offcanvas, accordion, modals e formulários.
- **Bootstrap Icons:** ícones utilizados no rodapé.
- **JavaScript:** controle do modo claro/escuro.
- **LocalStorage:** armazenamento da preferência de tema do usuário.
- **GitHub Pages:** publicação do projeto online.
